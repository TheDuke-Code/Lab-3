# Norrgläntan

Har byggt en fiktiv sida åt Norrgläntan som en skoluppgift

## Projekt

Jag fick en Wireframe av skolan och sen gjorde jag min egen Wireframe och egen Mockup av sidan i figma, målet var att lära mig allt jag kan om denna del i skapandet. En väldigt rolig uppgift men även otroligt givande!

## Teknik

- HTML - Semantisk byggd sida
- CSS Flexbox, mobilvänlig med Media queries.
